# Rafylabs

Software engineer & security researcher. I build production systems — web apps, APIs, automation pipelines — and use that depth to find vulnerabilities: logic flaws, architectural weaknesses, and exploitation paths that require reading source, not just scanning surface.

### Security Research

- **Bug Bounty:** [HackerOne @rafylabs](https://hackerone.com/rafylabs)
- **Focus:** Web application security, API abuse, Electron/desktop app analysis, authentication bypass
- **Methodology:** Source-level analysis → deterministic PoC → validated impact. No theoretical reports.
- **Portfolio & Writeups:** [rafylabs.com](https://rafylabs.com/)

Engineering and security are the same skill applied in opposite directions. Understanding how systems are built is the fastest path to understanding how they break.
